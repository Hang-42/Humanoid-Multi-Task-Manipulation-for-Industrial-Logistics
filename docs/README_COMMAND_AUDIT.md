## 当前配置和环境限制

- V53 Revo1：四个任务在配置中均标记启用，但本地对应模型目录均缺失。
- V53 lejuclaw：仅 `lj` 在配置中启用，`kd12/cz/lp` 被阻止；`lj` 本地权重同样缺失。
- V55 Revo1、lejuclaw、Linker Hand：均为未完成的配置模板，需要补齐并验证后部署。
- 识别脚本的 SSH 地址参数只影响识别，不会自动写回机器人配置中的网络字段。
- 密钥登录和 `sudo -n` 是两项独立条件；推理/恢复的 SSH 批处理不会交互询问账户密码。
- Linux 工作站需有 Bash、SSH/SCP、tmux、ip、ss 等命令；上下位机需有匹配的 ROS Noetic 与厂商工作空间。
  识别脚本本身只要求 Python 3.8+ 和 SSH，不要求启动 ROS。
